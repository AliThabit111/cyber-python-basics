# Cyber Python Basics

Nine small Python programs for learning security basics. Python 3.8+, no external packages.

| # | File | What it does |
|---|------|--------------|
| 1 | `01_password_strength_checker.py` | Checks if a password is strong |
| 2 | `02_caesar_cipher_encryption.py` | Encrypts text with a Caesar cipher |
| 3 | `03_caesar_cipher_decryption.py` | Decrypts Caesar-cipher text |
| 4 | `04_generate_random_password.py` | Generates a random password |
| 5 | `05_hash_password_sha256.py` | Hashes a password with SHA-256 |
| 6 | `06_file_integrity_checker.py` | Computes a file's hash |
| 7 | `07_simple_port_scanner.py` | Checks whether a port is open |
| 8 | `08_ip_address_validator.py` | Validates an IPv4 address |
| 9 | `09_brute_force_simulation.py` | Finds a password in a small list |

## Run

```bash
python 01_password_strength_checker.py
```

## Disclaimer

For educational use only. Only scan systems you own or have permission to test.
